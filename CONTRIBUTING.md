# Contributing

Contributions are welcome for the Windows community port.

## Development expectations

- Keep the app native to Windows and follow the existing WPF architecture.
- Prefer component-level design over unnecessary abstraction.
- Document any upstream code or assets reused from Orion in the project documentation.
- Avoid fabricating API endpoints or catalog schemas.
- Preserve GPL-3.0 compliance and attribution requirements.
- Run unit tests for persistence and catalog logic before submitting changes.

## Pull request guidance

- Keep changes focused and well-scoped.
- Include tests for behavior changes.
- Describe any unfinished or intentionally stubbed work.
- Ensure code remains buildable on Windows targets.
